# Pixel shorts

Vertical pixel-art Reels/Shorts (science, Indian mythology, fiction fables), built with HyperFrames.

**House style → [STYLE_GUIDE.md](STYLE_GUIDE.md):** sharp HD pixel art (360×640, light dither), a dark outline on every
living character, narration on every video with a voice that fits each character, open-source sound effects.

- Start a video: `videos/_engine/new_video.sh <slug>` (from `videos/_template`)
- Reference for the current look: `videos/style-sample/renders/video.mp4`
- Voices: `videos/_engine/VOICES.md` · Sounds: `videos/_engine/SOUNDS.md` (`python3 videos/_engine/osfx.py packs` downloads the CC0 packs)
- Workflow for Claude: `CLAUDE.md` → `.claude/skills/pixel-short/SKILL.md`
