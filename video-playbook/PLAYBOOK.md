# Video Style Playbook: the "Field Notebook" Hindi Explainer

A breakdown of the 4 reference videos and a repeatable recipe for making new ones in the same style.

| # | Topic | Length | Category |
|---|-------|--------|----------|
| 1 | Tardigrade (water bear) | 2:35 | Weird nature / science |
| 2 | Rabies: why it kills even though a vaccine exists | 2:57 | Health / India public-interest |
| 3 | Cipla & the $1-a-day AIDS drug (India's patent law) | 2:50 | India history / business / law |
| 4 | Jewel wasp: the cockroach "zombie maker" | 2:19 | Weird nature / horror-biology |

Reference frames are in `reference/`.

---

## 1. Technical format

| Spec | Value |
|------|-------|
| Aspect / resolution | 9:16 vertical, 720×1280 (export 1080×1920 if you can) |
| Frame rate | 30 fps |
| Length | 2:15–3:00 (long Shorts/Reels; not 30-second clips) |
| Loudness | **-14 LUFS integrated** (YouTube/Instagram standard), measured on all 4 |
| Audio gaps | **None.** No silence longer than 0.3 s anywhere. Music bed runs under everything. |
| Narration speed | **~170–200 words/min**: fast, but clear |
| Narration line length | **2.4–3.3 s per sentence** |
| Hard scene changes | Roughly every 6–8 s (17–22 per video) |
| Visual changes inside a scene | Every 1.5–3 s: something new appears on every narration line |

**Golden rule: one narration line = one visual beat.** The screen never sits still for longer than one sentence.

## 2. Visual style ("Specimen File / Field Notebook")

### 2.1 The canvas (same in every video, which builds brand recognition)
- **Aged kraft/manila paper** background with grain, a soft vignette, and faint **vertical fold creases**.
- **Punch-hole dots** down the left margin, like a binder page.
- **Header strip** at the top of every frame:
  - Left: tiny monospace uppercase **chapter label** (`HOOK`, `THE NAME`, `MICROSCOPE`, `THE TUN`, `THE NERVE`, `THE RACE`, `THE BRAIN`, `HYDROPHOBIA`, `THE LAW`, `CUT`, `XRAY`).
  - Right: `FIG. 1`, `FIG. 2` … (restarts at 1 in each chapter).
  - Thin rule line underneath.
  - This makes the video feel like a dossier and tells the viewer, subconsciously, that the story is progressing.
- **Dark variants** that alternate with the paper:
  - Charcoal/black "lightbox" for anatomy, x-ray, and microscope scenes (brain, nerves, cockroach x-ray).
  - Starfield black for space scenes.
  - Sepia-toned photographic backgrounds for history (pharmacy shelves, Supreme Court, factory).
  - Lined notebook paper with a red margin line for "explaining a rule" chapters (the patent-law section).
- Alternating light paper and dark backgrounds resets attention every few scenes.

### 2.2 Typography
- **Headline font:** condensed, heavy, ALL CAPS grotesque. Free matches: *Anton*, *Bebas Neue*, *Oswald Bold*, *League Gothic*.
- **Label font:** monospace (*IBM Plex Mono*, *Space Mono*, *Courier Prime*) for chapter labels, specimen tags, scale bars, sources (`SOURCE: WHO`), and terminal text.
- **Two-tier headline formula**, used almost every time:
  - Line 1, small, dark brown/black (or cream on dark): the setup → `ONCE SYMPTOMS`
  - Line 2, BIG, **brick red**: the punch → `START`
  - More examples: `RABIES HAS A / VACCINE` → `YET IT / KILLS` · `IT LIVES / EVERYWHERE` · `LOOKS DEAD / IS ALIVE` · `TO ITS OWN / GRAVE` · `TOO / HEAVY`
- **Colours (approximate):**
  - Paper `#D9C9A3` · Ink brown `#2B1D14` · Accent red `#C0392B` · Cream on dark `#EDE3CC` · Dark bg `#1E1B18` · Secondary accent: muted teal-green `#4E9C86` (used only for "good/with protection" vs red "bad").
- **Text is not full subtitles.** Only 1–4 keywords from the line appear, word by word, timed to the voice. The punch word lands exactly as the narrator says it.
- **Annotation effects:** a red strikethrough (`IT WON'T ~~KILL~~`, `~~NOT THE MEDICINE~~`), hand-drawn red circles, red ticks ✓ and crosses ✗, a red marker underline, and a highlighter-tape block behind a word.

### 2.3 Imagery: photoreal cut-outs on paper (a collage look)
- The main subject is a **photoreal, background-removed cut-out** (tardigrade, wasp, cockroach, dog, vaccine vial) with a soft drop shadow, so it looks like a specimen pinned to a page.
- Supporting props in the same realistic-vintage style: steel stopwatch, mercury thermometer, glass vial, milk-can cryo container, dropper, ruler with pencil (for scale), magnifying glass, specimen display case.
- **Recurring "info-props" (the signature of this style):**

| Prop | Used for | Example |
|------|----------|---------|
| **Split-flap / flip-clock counter** | Any big number, year, or day count | `2019`, `40`, `56,00,000`, `~5,700`, `DAY 01 → 05 → 14` |
| **Torn-paper label card** | Captions, definitions, prices | `$33 A DAY – ₹1,546 ROZ`, `THE PATENTS ACT 1970` |
| **Rubber stamp** (red, slams in) | Verdicts and twists | `REFUSED`, `HIJACKED`, `NOT A MOVIE` |
| **Red name bar + Latin name** | Subject reveal | `TARDIGRADE / PHYLUM TARDIGRADA`, `JEWEL WASP / AMPULEX COMPRESSA` |
| **Specimen tag** on a string | Labelling the subject | `SPECIMEN 01 / HYMENOPTERA`, `PREY` |
| **Circular microscope viewport** | Anything small | Scale bar `0.1 MM` |
| **X-ray / anatomy view** | Inside the body | Virus travelling up the nerve; larva inside the cockroach |
| **Pictogram grid** | Proportions | 100 people, 100 red = "100 OUT OF 100 DIE" |
| **Hand-drawn bar chart** | Before/after | DSUP 40% less damage; price drops |
| **Checklist with ✗** | "What stops" | ~~FOOD~~ ~~BREATH~~ |
| **Terminal / progress bar** | Tech metaphor | `> HACKING BRAIN_ 89%` |
| **Calendar / ticket / WANTED poster / case file** | Metaphor props | `TRAVEL TIME 1 WEEK`, `ADMIT ONE – HORROR`, `WANTED: RABIES VIRUS` |

- **Visual metaphors explain the mechanisms.** Examples: the blood-brain barrier drawn as **castle walls around the brain**, the vaccine as **a WANTED poster shown to immune cells**, and dormancy as **a pause button / flat-lining ECG**. Each abstract idea gets one concrete physical object.

### 2.4 Motion and editing
- **Slow push-in** (Ken Burns) on almost every still. Nothing is ever fully static.
- Elements **pop/slide in with a little overshoot**; cards drop in at a slight rotation; stamps **slam in** at 110% scale and settle to 100%.
- Text appears word by word; the red punch word appears last, sometimes with a fade-up from 30% opacity.
- **Match transitions** keep the same subject between scenes (tardigrade → tun in the same microscope circle; vaccine vial carried from hook to later scene).
- **Paper-tear reveal** for shock moments (the dog bursting through torn paper on `KILLS`).
- **Colour-state change** for status: the microscope tint turns green → beige → grey as the tardigrade dries and goes dormant.
- **Counters roll** (split-flap animation) instead of numbers simply appearing.
- Hard cuts are mostly on chapter changes. Within a chapter, the frame **builds up** element by element rather than cutting.

## 3. Voice-over style

- **Language:** conversational Hindi with English technical words left in English: *radiation, metabolism, immune system, patent, saliva, symptoms, radioactive tracking*. That's "Hinglish" as an Indian viewer actually speaks it.
- **Talks to the viewer directly:** `सोचो…`, `समझ लो…`, `ज़रा सोचो…`, `देखो…`, `आपके घर की दीवार पर…`
- **Tone:** confident, slightly dramatic documentary narrator; energetic but not shouting. A male voice in all 4.
- **Short sentences.** One idea per sentence, 2–3 seconds each. Stack them rapidly.
- **No dead air.** The next line starts within ~0.2 s, which creates the "can't stop watching" pace.
- **Numbers spoken the Indian way** and localised: `$33 – उस वक़्त के लगभग 1,500 रुपये, वो भी रोज़`, `56 लाख`, `100 में से 100`.
- **Transition phrases** (steal these):
  - `अब सवाल ये है कि…`
  - `और सोचने वाली बात तो ये है…`
  - `दरअसल इसके अंदर एक और राज़ है…`
  - `अब आता है सबसे अजीब हिस्सा…`
  - `फिर आता है, February 2001…`
  - `हालाँकि 2005 में कहानी पलट गई…`
  - `और ये अंदाज़े से नहीं होता, scientists ने…`
  - `और सबसे डरावनी बात ये है कि…`
  - `आख़िर इंडिया ये कर कैसे सका?`

## 4. Script structure (the blueprint all 4 follow)

```
0:00–0:10  HOOK           Paradox or impossible-claim stack. No name yet.
0:10–0:30  REVEAL         Name / identity card + size or scale + nickname.
0:20–0:50  INDIA ANGLE    Why an Indian viewer should care (stat, place, person).
0:45–2:00  MECHANISM      Step-by-step "how does it work", in 3–5 chapters,
                          each chapter opened by a question.
           ↳ PIVOT        "अब आता है सबसे अजीब हिस्सा" – escalate mid-way.
           ↳ PROOF        Dated experiment / study / court case with a number.
2:00–2:50  PAYOFF         Twist, open question, or actionable advice.
```

### 4.1 Hook formulas (with the actual examples)

1. **Impossible-claim stack ("सोचो, एक ऐसा…")**: 3 superpowers in 20 seconds, then the tiny-size reveal.
   > सोचो, एक ऐसा जानवर जो space के खुले vacuum में भी ज़िंदा बच जाता है… absolute zero तक जमा दिया गया, फिर भी वापस जाग सकता है… जितना radiation एक इंसान को हज़ार बार मार दे, वो भी झेल सकता है… और ये बस आधा millimetre का होता है।

2. **Paradox question + absolute stat**:
   > ऐसा क्यों है कि rabies की vaccine होते हुए भी ये एक जानलेवा बीमारी है? … एक बार symptoms शुरू हो गए, तो rabies 100 में से 100 लोगों की जान ले लेता है।

3. **Shocking before/after number + mystery person**:
   > साल 2001। AIDS के इलाज का खर्चा: एक दिन का $33… आज वही इलाज 20 cents में… और ये दाम गिराने के पीछे इंडिया के एक आदमी का हाथ था।

4. **Horror framing + "it's real" denial**:
   > सोचो, एक ऐसा कीड़ा जो किसी को मारता नहीं, बल्कि उसका दिमाग hack करके उसे zombie बना देता है… और फिर अपने बच्चों को उसे ज़िंदा खाने देता है। ये कोई horror movie नहीं है, ये बिल्कुल सच है।

**Hook rules observed:**
- On screen within **0.5 s**: a subject cut-out and the first words. There is no logo or intro.
- The first visual is the single most iconic object (vial, wasp, tardigrade in space).
- **Withhold the name** until after the claims (tardigrade name at 0:26, jewel wasp at 0:12).
- Every hook contains a **number** or an **absolute** ("100 में से 100", "हज़ार बार", "2 गुना बड़ा").

### 4.2 Body rules
- Open each chapter with a **question** the viewer now wants answered ("तो इतना छोटा जानवर ये करता कैसे है?").
- Use **mechanism, not trivia**: explain *how*, step by step (bite → muscle → nerve → spine → brain).
- Insert **one escalation pivot** around the 60% mark.
- Add **one dated proof point**: 2007 satellite test, Dsup protein cutting damage by 40%, radioactive-tracking study, Novartis 2013 Supreme Court case.
- Mention **one Indian hero/place/fact**: Tamil Nadu species named after Dr. APJ Abdul Kalam; Cipla & Dr. Yusuf Hamied; 2 of 3 WHO-approved rabies vaccines made in India.

### 4.3 Ending formulas (there's no "like & subscribe" in any of them)
- **Callback + open question:** `तो क्या अब चाँद पर tardigrades हैं? शायद नहीं… चाँद पर वो पानी ही नहीं जो इन्हें जगा सके।`
- **Future stakes question:** `अगली महँगी दवाई आ चुकी है: cancer की, मोटापे की। सवाल सिर्फ़ इतना है: क्या वो एक लाइन काफ़ी होगी?`
- **Actionable PSA:** `कुत्ता काटे तो ज़ख़्म को तुरंत साबुन और बहते पानी से 15 मिनट तक धोइए, और उसी दिन vaccine लगवाइए।`
- **Scale-up wonder:** `एक अकेला wasp दर्जनों cockroaches के साथ यही कर सकता है… ज़रा सोचो, nature में किस-किस तरह के creatures हैं।`

Endings either loop back to the hook, create comment bait (a question), or give the viewer something useful. Those drive comments, shares, and rewatches.

## 5. Sound design

What the measurements show: the whole mix sits at -14 LUFS, a music bed runs continuously (never drops to silence), and the voice sits clearly on top. The SFX list below is inferred from the visual events and from transient spikes in the audio, not from isolating each sound, so treat it as a strong starting point rather than an exact copy.

- **Music bed:** low, dark, pulsing documentary/suspense underscore (ambient synth pad + soft percussion pulse). Keep it **-18 to -22 dB under the voice**, and duck it with sidechain compression.
- **SFX palette (match each to a visual):**

| Visual event | SFX |
|--------------|-----|
| Punch word / red text slam | Low "thud" / boom hit |
| Rubber stamp | Stamp thunk |
| Split-flap counter | Mechanical flap ticking |
| Card drop / paper slide | Paper rustle / swish |
| Paper tear reveal | Tear rip + impact |
| Scene change | Soft whoosh |
| Stopwatch / time pressure | Clock ticking |
| Terminal text / progress bar | Keyboard clicks / digital blips |
| Check ✓ / cross ✗ / circle | Pen/marker scribble |
| Microscope zoom-in | Glassy shimmer / riser |
| Horror beats | Low drone, heartbeat |

- **Mix order:** Voice (loudest, compressed, EQ'd with a slight high-shelf for clarity) > SFX (short, never on top of a key word) > music.

## 6. Topic research method

**What these topics have in common:**
1. **A paradox or superlative in one sentence** ("vaccine exists but 100% fatal", "survives space", "AIDS drug went from $33 to 20 cents").
2. **Visualisable mechanism**: you can draw the "how" step by step.
3. **An India hook**: an Indian statistic, place, person, or law.
4. **Verifiable numbers and dates** (WHO, peer-reviewed studies, court rulings, news).
5. **Evergreen**: still true next year.

**Research workflow:**
1. **Find:** Wikipedia "unusual"/"list of" pages, r/todayilearned, Kurzgesagt/Veritasium topics, *New Scientist*, *Down To Earth*, *The Hindu* Sci-Tech, WHO fact sheets, Indian court judgments.
2. **Test the one-line hook:** if you can't write "सोचो, एक ऐसा ___ जो ___" or "ऐसा क्यों है कि ___ फिर भी ___?", drop the topic.
3. **Find the India angle** (search "<topic> India", "<topic> ICMR", "<topic> Indian scientist").
4. **Collect 5–8 hard numbers** with sources: size, %, year, count, ₹ price.
5. **Fact-check every number against 2 sources**; keep a source list (the videos show `SOURCE: WHO` on screen).
6. **Find the twist/ending**: the "but…", the unanswered question, or the practical takeaway.

**Topic ideas in the same vein** (verify facts before scripting):
- Immortal jellyfish: an animal that resets its own age
- Cordyceps: the fungus that controls ants' minds
- Snakebite in India: why tens of thousands die each year, and how antivenom is made from horses
- Axolotl: regrows its brain and heart
- Naegleria (brain-eating amoeba) cases in Kerala
- How Amul / Operation Flood made India the world's largest milk producer
- Why India makes so many of the world's vaccines (Serum Institute)
- Bdelloid rotifers: living without males for millions of years
- Mantis shrimp: the punch faster than a bullet's acceleration
- Generic drugs: why the same medicine costs ₹10 vs ₹100

## 7. Production workflow

1. **Script** (Hindi/Hinglish, ~450–550 words for 2:30–3:00). Write **one sentence per line**.
2. **Beat sheet:** next to each line, write **chapter label · FIG # · on-screen words (setup / red punch) · visual/prop · SFX**. (Template below.)
3. **Voice-over:** record it yourself (USB mic, closet/blanket room) or use a Hindi AI voice (e.g. ElevenLabs multilingual). Cut out every breath gap longer than about 0.2 s.
4. **Assets:**
   - Subject cut-outs: AI image generator with a consistent prompt (below) → remove the background → add a soft shadow.
   - Build **one master paper template** (background + header strip + punch holes) and reuse it in every video.
   - Build reusable prop packs: flip-counter, torn label, stamp, specimen tag, microscope circle, x-ray frame.
5. **Edit:** After Effects / CapCut / Premiere / DaVinci. Lay the VO down first and **cut visuals to the voice**, not the reverse.
6. **Sound:** music bed → duck under VO → SFX on every pop/slam → master to **-14 LUFS**, true peak -1 dBTP.
7. **Export:** 1080×1920, 30 fps, H.264.

**AI image prompt template for cut-outs:**
> Photorealistic scientific illustration of a [SUBJECT], side view, isolated on plain background, soft studio lighting, high detail, natural colours slightly desaturated, vintage museum specimen look, no text

## 10. Checklist before publishing

- [ ] Hook has a paradox/claim + a number within 5 s; first frame is the iconic subject
- [ ] Name revealed only after the hook
- [ ] India angle within the first 45 s
- [ ] Every narration line has a new visual element
- [ ] Every chapter opens with a question; one "सबसे अजीब हिस्सा" pivot
- [ ] At least one dated proof point; every number verified with 2 sources
- [ ] Ending = callback question, future question, or actionable advice
- [ ] Two-tier headline (small dark + big red) on every key beat
- [ ] Header strip (chapter label + FIG #) on every frame
- [ ] No silence longer than 0.3 s; music ducked under VO; SFX on every pop/slam
- [ ] Master at -14 LUFS, 1080×1920, 30 fps
